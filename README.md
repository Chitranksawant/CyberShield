# CyberShield - Instagram Comment Moderation

CyberShield is an AI-powered Instagram comment moderation tool.  
It uses the Perspective API to detect toxic comments and can automatically delete them from your Instagram posts.

---

## Features
- Analyze all comments on your Instagram posts.
- Detect toxic comments using Perspective API.
- Option to preview toxic comments without deleting (Preview Mode).
- Automatic deletion of highly toxic comments.
- Dashboard and reports with stats and deleted comments history.
- Dark mode, sidebar, and responsive UI.
