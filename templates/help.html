CyberShield Help & Support

Welcome to CyberShield! Here’s how you can use the app effectively:

1. Dashboard

View all Instagram comments here. Highly toxic comments are automatically deleted (or marked in Preview Mode).

2. Reports

Check analytics of flagged comments and toxicity trends over time.

3. Settings

Enable/disable notifications and switch between light and dark themes.

4. Preview Mode

If Preview Mode is enabled, toxic comments will be detected but not deleted. This is useful for testing without affecting real comments.

5. Contact Support

If you encounter any issues, please reach out to our support team at support@cybershield.com.

6. Tips

  • Click “Refresh Comments” in the Dashboard to update the latest comments.
  • Use dark mode for better visibility at night.
  • Keep Preview Mode enabled when testing new features.
